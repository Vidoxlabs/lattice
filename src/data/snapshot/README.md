# Offline content snapshot

`pipeline.json` is generated by `npm run snapshot:refresh`. It records the documentation manifest, public repository status, Vivarium pins, and digest-verified README documents used when the network is unavailable. The stored document text carries the site's neutral-vocabulary mapping (`src/lib/content/neutral-vocabulary.mjs`), and the manifest digests in the snapshot are computed over that stored text, so the offline fallback still verifies; the upstream digests live in the manifest a connected build fetches. Its `capturedAt` date appears on affected pages. Do not edit the JSON by hand.
