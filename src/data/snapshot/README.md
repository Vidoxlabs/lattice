# Offline content snapshot

`pipeline.json` is generated by `npm run snapshot:refresh`. It records the documentation manifest, public repository status, Vivarium pins, and digest-verified README documents used when the network is unavailable. The stored document text carries the site's neutral-vocabulary mapping (`src/lib/content/neutral-vocabulary.mjs`); each manifest record keeps the upstream digest and gains `storedSha256`, the digest of the text this snapshot stores, so the offline fallback still verifies and a live manifest can tell a fresh snapshot from a stale one. Its `capturedAt` date appears on affected pages. Do not edit the JSON by hand.
