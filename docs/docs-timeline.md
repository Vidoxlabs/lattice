# lattice development timeline

All dates use America/New_York (ET).

## 2026-11-25

- Slice 1: created the public repository, configured squash-only pull-request merges and main protections, and drafted the engineering and architecture records.
- Slice 2: added the pinned Astro and Cloudflare toolchain, CI, source and built-output scrubbing, a smoke page, route checks, and Chromium/WebKit coverage. Verified locally with two unit tests, one route test and two browser tests.
- Slice 3: pinned and synced videsign, added verified brand digests, ported the public shell components, added persistent light/dark and motion controls, and added raw-color, arbitrary-value and token-reference tests.
- Slice 4: added the complete public route set, digest-checked README summaries, the Vivarium pin table, repository filters and detail pages, canonical-host middleware, security.txt, and product-naming tests.
- Slice 4 fixes: the browser stage now runs the local Worker runtime in its own process group and exits with the test code, CI jobs carry a 20-minute timeout, the CodeQL skip for JavaScript-free heads is carried on the stack, the sleep-ban test moved to its own file, private design tokens are aliased at sync time with the needle scan enforced everywhere, and the canonical-host check runs ahead of static asset serving in a generated Worker entry with `run_worker_first`. Verified locally: `CI=1 npm run check` passes 9 unit, 5 route and 4 browser tests and exits in seconds with no leftover server processes; alternate hosts redirect 301 and the canonical host serves 200 under the local Worker runtime.
- Slice 5: added the build-time content and status pipeline: schema-validated manifest and status contracts (the status schema mirrors the docs#6 proposal at its commit and is labelled proposed), digest-verified README documents, the GitHub REST fallback labelled gathered by the site, the committed offline snapshot with its refresh command, the `/api/status` Worker route with Cache API caching and graceful degradation, and the client status refresh. Verified with `CI=1 npm run check`: 15 unit, 6 route and 10 browser tests on Chromium and WebKit, all passing; the canonical-host redirect is now active in the Worker deploy and covered by browser tests on both engines.
- Slice 6: added build-time SVG generators (Vivarium system map, the self-updating pipeline, per-repository activity timelines, documentation freshness), each with a title, a description and a closed text-table equivalent, styled only through tokens from data attributes. Ported the orbital hero (quiet, pausable, reduced-motion aware) and the family stack diagram with live CI and drift state, and added the family surfaces stylesheet and hero palette to the publish-filtered sync. Verified with `CI=1 npm run check`: 20 unit tests, 6 route tests, 20 browser tests on Chromium and WebKit, all passing in both themes with no leftover server processes.
- Slice 7: added documentation ingestion: a content-layer loader over the digest-verified corpus (every manifest markdown file plus the hub's own pages), relative links rewritten to site routes or exact upstream files, Mermaid blocks shown as labelled source, rendered HTML sanitized, claim-status lines badged, the portal layout with section navigation including the Vivarium section, source and edit-upstream labels on every page, the search index at `src/data/docs-index.json`, and the disabled enrichment hook with ADR-0004. Eight upstream pages that fail the public-safety scan render as labelled placeholders linking upstream. Verified with `CI=1 npm run check`: 28 unit tests, 9 route tests, 26 browser tests on Chromium and WebKit, all passing.
- Slice 8: added the grounded chat on the pinned family contracts: seed's provider seam (deterministic mock default; OpenAI-compatible and Gemini behind `CHAT_ALLOW_CLOUD=1`), capillary's literal search and bounded provenance packets over the docs index, drosera tool faces (`docs.search`, `repos.read`) under seed's tool-id grammar, and a thin head-agent loop mirroring bloom's shape. `POST /api/chat` streams Server-Sent Events with session, plan, tool traces, citations and tokens, guarded by origin checks, rate limiting (binding or documented fallback), body, count, character and timeout caps, with no message-body logging. The chat page and the dock on every page share one same-origin script; the assistant name defaults to "Vidoxlabs assistant". Verified with `CI=1 npm run check`: 38 unit tests, 9 route tests, 32 browser tests on Chromium and WebKit, all passing, including a streamed mock answer with citations.
